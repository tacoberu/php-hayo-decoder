Comments

-- a single line comment

{- a multiline comment
   {- can be nested -}
-}

Here's a handy trick that every Hayo programmer should know:

{--}
add = x y -> x + y
--}

Just add or remove the } on the first line and you'll toggle between commented and uncommented!

Records

...

-- create records
origin = { x: 0, y: 0 }
point = {
  x: 3
  y: 4
}


-- access fields
origin.x == 0
point.x == 3

-- field access function
List.map .x [ origin, point ] == [ 0, 3 ]

-- update a field
{ point | x = 6 } == { x = 6, y = 4 }

-- update many fields
{ point | x = point.x + 1, y = point.y + 1 }

Destructuring assignment

a, b = (1, 2)

x :: xs = [1, 2, 4]
[x, y, ...xs] = [1, 2, 4]

{x: a, y: b} = {x: 1, y: 4}

Conditionals

if powerLevel > 9000 then "OVER 9000!!!" else "meh"

If you need to branch on many different conditions, you just chain this construct together.

if key == 40 then
    n + 1

else if key == 38 then
    n - 1

else
    n

You can also have conditional behavior based on the structure of algebraic data types and literals

match maybeList {
  Just xs -> xs
  Nothing -> []
}

match xs {
  []      -> Nothing
  x :: xs -> Just (x, xs)
}

match n {
  0 -> 1
  1 -> 1
  _ -> fib (n-1) + fib (n-2)
}

Each pattern is indentation sensitive, meaning that you have to align all of your patterns.

Functions

square = n ->
  n^2

hypotenuse = a b ->
  sqrt (square a + square b)

distance = (a, b) (x, y) ->
  hypotenuse (a - x) (b - y)

Anonymous functions:

squares =
  list.map (n -> n ^ 2) (list.range 1 100)

Local functions:

calc = x ->
  inc = x ->
    increment = 1
    x + increment
  x + y + (inc y)

Operators

In addition to the normal math operations for addition and subtraction, we have the (<|) and (|>) operators. They are aliases for function application, allowing you to write fewer parentheses.

viewNames1 names =
  string.join ", " (list.sort names)

viewNames2 names =
  names
    |> list.sort
    |> string.join ", "

-- (arg |> func) is the same as (func arg)
-- Just keep repeating that transformation!

Historical note: this is borrowed from F#, inspired by Unix pipes.

Applying Functions

-- alias for appending lists and two lists
append xs ys = xs ++ ys
xs = [1,2,3]
ys = [4,5,6]

-- All of the following expressions are equivalent:
a1 = append xs ys
a2 = xs ++ ys

b2 = (++) xs ys

c1 = (append xs) ys
c2 = ((++) xs) ys

The basic arithmetic infix operators all figure out what type they should have automatically.

23 + 19   -- Number
2.0 + 1   -- Float

6 * 7     -- Number
10 * 4.2  -- Float

100 // 2  -- Int
1 / 2     -- Float

Modules

version = 4
name = "package"

export "package.name.foo#1@vendor" {
	version: verson
	name: name
}

Qualified imports are preferred.

dump package.name.foo#1@vendor.version

-- or make shortcut
pn = package.name.foo#1@vendor
dump pn.version

Type Annotations

answer = -- this is alias
  42

answer =
  cast 42 Int

factorial = (n: Int) : Int ->
  list.product (list.range 1 n)

distance = ({ x: Float, y : Float}) : Float ->
  sqrt (x^2 + y^2)

xy = {x: 10, y: 55}
distance xy

person = (n: Int 0 4) : Int -> -- dependenci types
  list.product (list.range 1 n)
